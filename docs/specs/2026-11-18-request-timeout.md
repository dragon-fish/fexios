# HTTP 请求取消与超时

## 目标

调用方可主动取消一组请求。单个请求的超时只终止该请求，调用方能分别处理手动取消和超时。

## 行为

- 每次请求有独立的取消状态，调用方的 `abortController` 只向该请求传递取消信号。多个请求可共享同一个 controller，主动取消时通过 `FexiosError.cause` 保留取消原因。
- 正数 `timeout` 以毫秒计，从开始 fetch 到响应正文读取和解析完成，覆盖有响应头但正文仍在传输的情况。非正数关闭超时，手动取消仍有效。准备请求的 hooks 和正常响应完成后的 `afterResponse` hook 各自独立于此计时。
- 第一个取消信号决定错误码。超时使用 `TIMEOUT`，主动取消使用 `ABORTED`，以便调用方区分重试和主动中止。

## 验收

验证已取消和进行中的请求、共享 controller 的并发请求、响应头先到的慢响应，以及请求结束后计时器清理。
